# لوحة إدارة الرمز الطبي

تطبيق دسكتوب ويندوز بلغة Dart يطابق خصائص لوحة الإدارة في مشروع React.

## التشغيل

```bash
cd medical_qr_admin
flutter pub get
flutter run -d windows
```

## الدخول

- البريد: `admin@medical.iq`
- كلمة المرور: `Admin123`

## ما يغطيه التطبيق

- لوحة التحكم مع بطاقات قابلة للنقر ومخطط الدخول اليومي
- إدارة الأطباء: موافقة، تعليق، إعادة تفعيل، إشعار وسجل تدقيق
- تفعيل الاشتراكات مع معاينة التواريخ، البطاقة، CVV، والسجل
- إدارة المرضى وصفحة السجل الطبي الكاملة
- إدارة المنشورات مع الإعجابات والتعليقات والحذف
- تعديل ملفات المستخدمين بكل الحقول الطبية والمهنية والشهادات
- المظهر مع معاينة حية وحفظ لكل إعداد
- سجلات التدقيق بكل أنواع الإجراءات والإحصاءات وتحميل المزيد
- التحليلات وتقرير النشاط الأسبوعي للأطباء
- الإعدادات، الملف الشخصي (شخصي / أمان / نشاط)، الإشعارات
